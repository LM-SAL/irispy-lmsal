``irispy.utils.response.get_latest_response`` now takes one observation time and returns one dictionary; call it once for each time. Given several times, it returned a list in which every response held the last time's effective areas, and a time array of one element gave a dictionary whose ``DATE_OBS`` was an array; both now raise a ``ValueError``. The time can now also be a string or a ``datetime``, anything ``sunpy.time.parse_time`` accepts, which raised an ``AttributeError``.

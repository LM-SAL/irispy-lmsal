``irispy.utils.red_blue.calculate_red_blue_asymmetry`` now takes each profile's peak, which ``min_intensity`` is tested against, only within ``velocity_range[1]`` of ``rest_wavelength``, and raises a ``ValueError`` when the window has no sample there; it took the brightest sample of the whole window, which can be another line, the end of the window or a spike. ``RBAQualityFlag.PEAK_AT_EDGE`` now flags a peak at the end of that range with the profile still rising beyond it, and ``RBAQualityFlag.NO_FINITE_DATA`` a pixel with no finite sample in it.

``irispy.utils.calculate_dust_mask`` is now ``irispy.utils.dust.calculate_dust_mask`` and takes a slit-jaw cube instead of an array. It now returns the IRIS pipeline's bad pixels for the cube's channel, placed in the cube's frame, which ``irispy.utils.dust.remove_dust`` repairs, instead of thresholding the data, which flagged most of a FUV frame but only the dark cores of the dust in 2832 images.

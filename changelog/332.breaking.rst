``irispy.utils.red_blue.calculate_red_blue_asymmetry`` no longer returns the ``"observed_profile"`` cube, so ``return_profiles=True`` adds only ``"interpolated_profile"``. To plot the input against velocity, use ``np.where((cube.data < 0) | cube.mask, np.nan, cube.data)`` against ``cube.axis_world_coords("em.wl")[0].to(u.km / u.s, doppler_rest=rest_wavelength, doppler_convention="optical")``.

``irispy.utils.red_blue.calculate_red_blue_asymmetry`` no longer returns the ``"observed_profile"`` cube, a float64 copy of the input with negative and masked samples set to NaN on a velocity axis, which held 1.2 GB for the Si IV 1403 window of the gallery example's raster; ``return_profiles=True`` adds only ``"interpolated_profile"``. To plot the input as it did, take ``np.where((cube.data < 0) | cube.mask, np.nan, cube.data)`` against ``cube.axis_world_coords("em.wl")[0].to(u.km / u.s, doppler_rest=rest_wavelength, doppler_convention="optical")``.

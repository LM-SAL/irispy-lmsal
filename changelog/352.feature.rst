Add ``irispy.net.LMSALClient``, a ``sunpy.net.Fido`` client for the IRIS archive at LMSAL. After ``import irispy.net``, ``Fido.search`` finds IRIS observations by ``a.Time`` with ``a.Instrument.iris`` or ``a.Provider("LMSAL")``, refined by the ``a.iris`` attrs ``ObsID``, ``Description``, ``Target``, ``XCen``, ``YCen`` and ``Product``, with one row per file in ``result["lmsal"]``, and ``Fido.fetch`` puts the files of each observation in a folder named after it.

`irispy.io.read_files` reads only the primary header of a gzipped raster before handing it to the reader, instead of inflating the whole file, `irispy.io.spectrograph.read_spectrograph_lvl2` inflates a gzipped file once instead of rewinding it for every extension, and `irispy.io.fits_info` opens its file once instead of three times.

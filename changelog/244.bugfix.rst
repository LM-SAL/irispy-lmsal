``irispy.io.read_files``, ``irispy.io.read_sji_lvl2`` and ``irispy.io.read_spectrograph_lvl2`` now raise a ``ValueError`` saying ``<file> is not an IRIS level 2 file`` (``… SJI file`` or ``… raster file`` from the two readers) for a file that is not FITS or a level 3 file, and the last two also for a directory or a file of the other product, instead of a warning about ``INSTRUME`` or an error from inside the reader.

`~irispy.io.read_files`, `~irispy.io.read_sji_lvl2` and `~irispy.io.spectrograph.read_spectrograph_lvl2` now raise ``ValueError("<file> is not an IRIS level 2 <product> file")`` for a directory, a file that is not FITS, a level 3 file or a file of the other product, instead of a warning about ``INSTRUME`` or an error from inside the reader.

`~irispy.io.read_files` extracts tar files into the ``irispy`` cache folder, ``astropy.config.paths.get_cache_dir("irispy")`` (``~/.cache/irispy`` by default), instead of next to the archive, so an archive in a read-only folder can be read and download folders stay clean; the new ``extract_dir=`` keyword picks another folder, and an extracted file that is shorter than its archive member is extracted again instead of being reused.

Test data for raster files written during a data gap, from the same observation as
raster/. The whole level 2 files are in
https://www.lmsal.com/solarsoft/irisa/data/level2_compressed/2014/03/29/

OBS 3860258481: Very large coarse 8-step raster 14x175 8s  Si IV   Mg II h/k   Mg II
(OBS_DESC as written). 180 rasters; r00066 and r00070 to r00073 have no data, r00067 and r00068 have no NUV
exposure.

iris_l2_20140329_140938_3860258481_raster_t000_r00066_test.fits
---------------------------------------------------------------

A file with no data: DATE_OBS and DATE_END are empty, XCEN, YCEN and SAT_ROT are 0,
every window is fill, EXPTIMEF, EXPTIMEN, XCENIX and YCENIX are 0 in all 8 rows of the
auxiliary table, PERCENTD and DATAVALS are 0, and the level 1 filename table has only
empty (A0) columns.
Source: iris_l2_20140329_140938_3860258481_raster_t000_r00066.fits,
        sha256 295338b5f4f1997cd9fa7dfdab4bf035c8a75d89318e9e12046dadf32d29facd

iris_l2_20140329_140938_3860258481_raster_t000_r00067_test.fits
---------------------------------------------------------------

A file with FUV data at step 2 only and no NUV exposure: EXPTIMEN is 0 in all 8 rows,
XCENIX and YCENIX are 0 in every row but step 2, and the NUV filename columns of the
level 1 filename table are empty (A0).
Source: iris_l2_20140329_140938_3860258481_raster_t000_r00067.fits,
        sha256 3fadef1de983aeccdcb77de1de1c17db4e88e73479239a957afa47b25ec03e08

Both files keep all 8 steps, every 10th slit row (110 of 1094) and every 10th
wavelength sample of all 9 windows. The windows hold the scaled values as float32
(BITPIX -32, no BSCALE or BZERO), as in raster/, with NAXISn, CDELTn and CRPIX2 for the
cut; the filename table declares TFIELDS = 9 for its 9 columns (the source says 7, see
tools/compress.py). Every other keyword and both tables are as in the source files.
Made:   python tools/compress.py <folder with the two source files>
